Outil 1 · prototypage IA

Installer Claude Code Desktop

L'app de bureau embarque Claude Code dans une interface graphique — aucun terminal requis.

C Claude Code Desktop 🔗 code.claude.com/docs/fr/desktop-quickstart

Abonnement Claude Pro / Max requis

  1. 1Téléchargez l'app (macOS / Windows) et lancez l'installeur.
  2. 2Connectez-vous avec votre compte Anthropic.
  3. 3Ouvrez l'onglet Code.
  4. 4Local → Sélectionner le dossier de votre projet.
  5. 5Choisissez un modèle, puis décrivez ce que Claude doit faire.
  6. 6Validez les changements : diff → Accepter / Rejeter.

DIGILITYX 30 / 36
7 Design sprint · étape 7

Tests utilisateurs

40 min
  1. 1Séparez votre groupe en 2.
  2. 2Un sous-groupe fait tester son travail au groupe voisin.
  3. 3L'autre va tester le travail d'un autre groupe (1 → teste 2 → teste 3…).
⚑ Les règles du test
✓Posez des questions ouvertes : « qu'avez-vous pensé de cette étape ? »
✓Restez neutre : pas de « c'était facile, non ? »
✕Évitez les questions qui orientent la réponse.
✓Écoutez attentivement, prenez des notes.
